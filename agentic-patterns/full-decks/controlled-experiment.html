Controlled experiment

Fixed rules, recorded moves, a result anyone can replay.

This deck covers the tenth loop pattern, the controlled experiment. It shows the shape of the pattern, the one loop in the library that fits it, what makes it an experiment, and when to use it.

Conceptual illustration

Where this pattern sits

Twenty patterns in three families

Sources: Design of Agentic Systems with Case Studies, Chapter 3. Anthropic, "Building Effective Agents". The Forward Future Loop Library (85 loops).

On entering: an empty map. The set of decks covers twenty patterns, grouped by the question each family answers.

Step 1: reasoning patterns. These describe how one agent orders its own thinking and tool calls.

Step 2: workflow patterns. These describe how several model calls are wired together.

Step 3: loop patterns. These are grouped by the check that keeps a long run honest.

Step 4: this deck is Controlled experiment, the tenth and last loop pattern.

The claim

This loop does not improve a product. It runs agents under fixed rules to learn how they behave.

The other loop patterns are about getting work done or checked. The loop tree calls this one the odd one out, because its goal is to learn something about agents.

Say this plainly: the grouping of the 85 loops into ten patterns is a judgment made from reading the catalog. None of it has been tested on real agent runs. Treat this deck as a reading of the pattern, not a result.

Part one

The shape

Fixed rules, recorded moves, a reproducible result

One slide. The loop tree gives this pattern a problem and a three-part shape, and nothing else.

Conceptual illustration

Structure

Fix the rules, record the moves, reproduce the result

Source: the loop tree, pattern 10. The line under each part is this deck's plain-word gloss.

On entering: the problem. You want to learn something about agents, not improve a product.

Step 1: fixed rules. The game and the scoring are the same in every run.

Step 2: recorded moves. Every choice is written down.

Step 3: a reproducible result. Someone else can take the record and get the same result.

Step 4: of the ten loop patterns, the loop tree calls this one the odd one out, because the goal is to learn.

Step 5: a loop is a prompt plus a real check plus a stop rule. For this pattern the loop tree gives only the problem and the shape. It does not name the check or the stop rule, and this deck does not invent them.

Part two

The loop

One loop in the library fits: 042, the Axelrod subagent arena loop

Every other pattern has several child loops. This one has a single child.

Conceptual illustration

Loop 042

Two agents choose, round after round, to cooperate or defect

Source: loop 042, The Axelrod subagent arena loop, Forward Future Loop Library. The average is computed as 180 ÷ 18.

On entering: two reasoning agents.

Step 1: each round, each agent chooses to cooperate or to defect, and then they play again. This is an iterated prisoner's dilemma.

Step 2: the agents are compared against two fixed players: one that always cooperates and one that always defects.

Step 3: the question the loop asks is whether agents learn retaliation, forgiveness and exploitation.

Step 4: the entry gives the size of the record as 18 matches and 180 rounds, replayable from recorded moves. That is 10 rounds a match on average. The entry's pros and cons are a reading of the catalog, not the catalog's own words: it calls the loop a research demo, not a work-improving loop.

Each part of the shape, shown on one small match

The other loop decks have a part on how the pattern fails. The loop tree lists no failure modes for this one, so this part shows the three parts of the shape at work. The match is a small simulation with scripted players. No model was run.

Simulation

Parts 1 and 2

Fixed rules, recorded moves: one match, round by round

Source: the loop tree, pattern 10. Scripted players and payoffs are this deck's illustration; scores are computed in code.

On entering: the fixed rules. On the left, the points per round. On the right, three scripted players: one always cooperates, one always defects, and Copycat cooperates first and then plays whatever the other player did last. These scripts stand in for the agents. No model was run, and the payoff numbers are an illustration, not the source's.

Step 1: round 1. Copycat cooperates, Always defect defects. Copycat gets 0 and Always defect gets 5.

Step 2: rounds 2 to 10. Copycat now copies the defection, so both defect and each gets 1 a round. The totals are 9 and 14. Every move is on the screen: that is the record.

Step 3: the other two pairings under the same rules: 30 to 30, and 0 to 50.

Part 3

Replay the record and the totals come out the same

Source: the loop tree, pattern 10, and the entry for loop 042. Both scoring rules are this deck's illustration; totals are computed in code.

On entering: the record of the match from the last slide, as two rows of moves.

Step 1: run 1, played by the scripts, totals 9 to 14.

Step 2: two replays. Each one scores the stored record again, and each gives 9 to 14. Same rules, same recorded moves, same totals.

Step 3: now keep the record and change only the scoring rule. The moves are the same and the totals become 18 to 22. The entry for loop 042 cautions that results depend on the scoring rule, which is why the rule has to be stated. The loop tree lists no failure modes for this pattern, so this deck does not add any.

Part four

When to use it

When the question is about the agents themselves

The loop tree says to pick the pattern from the problem you have. This pattern's problem is learning about agents.

Conceptual illustration

The decision and the checklist

Use it to learn about agents, not to improve a product

Source: the loop tree, patterns 1 and 10 and "How to use the tree". The caution is from the entry for loop 042.

Steps 1 and 2: the pair to tell apart. Both hold conditions fixed. A controlled experiment is for learning something about agents. Measure, change one thing is for making a number go the right way on a product. The split between learning and improving a product is the loop tree's own.

Steps 3 to 5: the three parts of the shape as checks: the goal, fixed rules, recorded moves.

Step 6: a caution from the entry for loop 042: results depend on the scoring rule, so state it.

Step 7: the pattern has one child loop. The loop tree's advice when no child fits is to write your own: keep the pattern's shape and supply your own check.

Takeaway

A controlled experiment teaches you about agents. Fix the rules, record the moves, and let anyone replay it.

What would change this reading: running the loop on real agents. Nothing here has been tested. This is the last deck in the set: five reasoning patterns, five workflow patterns and ten loop patterns.
