Use a bounded orchestration recipe

Using api-v2-spec and docs-v1, prepare a private /orders pagination migration plan.
Search the corpus, then choose at most 3 file-specific jobs from actual references. Give workers the original task, contract, exact file scope and required evidence fields.
Validate coverage and non-overlap before dispatch. Workers propose changes only; sources and tests are read-only.
Validate every packet. Synthesize a cited plan only with complete coverage, then check it again.
Budget: 1 planning call, up to 3 worker calls, 1 synthesis call, 0 retries, 90 seconds.
Return plan and untested assumptions, or BLOCKED/INCOMPLETE with the gap.
