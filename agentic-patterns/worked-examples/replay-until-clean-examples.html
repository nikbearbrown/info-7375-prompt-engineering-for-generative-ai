A continuation is not a replay

  • Invalid shortcutRun the missing migration in replay 2 and continue to the end.
  • Why it failsThe repaired instructions were never tried from a blank environment.
  • Required responseKeep the proposed documentation patch; discard that partial run.
  • Next valid runReset all state and start again at clone.
Illustrative teaching fixture. No agent workflow was run.6 / 10

This counterfactual is the source pattern’s defining distinction. Continuing is useful for diagnosing an obstacle but cannot be counted as a clean run of the corrected README. A development machine with an existing database might pass while the documented first-run path remains broken. A new revision resets any streak to zero even if the edit appears small.

A streak has both a reset and a ceiling

  • SuccessTwo full passes in a row, same revision, clean reset each time.
  • ResetAny failure or code/document change returns the streak to zero.
  • BudgetAt most six replays or 30 minutes, whichever comes first.
  • ExitMissing permission, broken reset or out-of-scope code defect: BLOCKED.
Illustrative teaching fixture. No agent workflow was run.8 / 10

If run 4 had failed, the streak would return to zero and the failure would be retained as a regression scenario. Budget exhaustion reports INCOMPLETE with the most recent revision, exact failed step and reset manifests. The loop may not lower the streak to one or skip a troublesome step. Two successes illustrate the selected gate; they do not statistically establish reliability across every supported platform.

A bounded fresh-clone prompt

On the demo repository, follow the README from step 1 in a new pinned environment with empty database, home, cache and browser profile. Make no undocumented setup changes. At the first obstacle, record the exact failing instruction; patch only README or its non-secret example config, then restart from scratch. Keep final assertions read-only. Require two consecutive complete runs on the same revision, including a note that survives reload. Reset the streak after any failure or edit. Stop after six replays or 30 minutes; report blockers instead of skipping steps. Return the patch, reset manifests, traces and unchecked platforms.
Illustrative teaching fixture. No agent workflow was run.9 / 10

This recipe describes a future authorized local documentation check, not work executed here. The owner supplies the pinned environment and final assertions. A reset harness, not a verbal promise, should enforce clean state. The stricter two-pass gate is an example choice; the source pattern permits one clean run or a preselected streak.
