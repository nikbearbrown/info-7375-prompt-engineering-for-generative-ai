Use a bounded fan-out recipe

Check field-guide-v1 against event-registry-v1 with exactly three independent workers: opening time, briefing room and accessible entrance.
Each returns its assigned key, extracted value and exact draft quote. Do not read other workers’ outputs or edit inputs.
Use at most 3 concurrent workers, 3 model calls, 0 retries and 30 seconds.
Code validates coverage, uniqueness and quote/value consistency, compares against the registry, then returns every discrepancy in fixed field order.
Any missing or failed worker makes the overall result INCOMPLETE. Do not vote, invent a result or add a synthesis call.
