A bounded Plan-and-Execute recipe

Before reading data, write a six-step plan with outputs C, S, V, D, R and A: read catalog, read count, validate, reconcile, render, verify. Use only pinned fixture INV-04. Define difference=counted−expected. Require unique matching SKUs and nonnegative integer counts. Give each handoff a pass condition. Execute only this plan; stop on any failed gate. Limit: six steps, 60 seconds, no retries or automatic replanning. Write only a local draft. Return the report only if the final artifact check passes; otherwise return BLOCKED, the failed condition and unrun steps.
