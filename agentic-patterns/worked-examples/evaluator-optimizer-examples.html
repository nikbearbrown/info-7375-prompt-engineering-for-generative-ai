Use a bounded revision recipe

Draft a CSV export guide, at most 60 words, using only ui-contract-v1.
A separate evaluator checks action order, active-filter scope, Ready before Download and unsupported claims. Return PASS, NEEDS_IMPROVEMENT or FAIL with source-keyed feedback.
For NEEDS_IMPROVEMENT, revise failed criteria and preserve correct content. Keep earlier drafts and latest feedback.
Stop only when evaluator and immutable source gates pass. Never edit the rubric or checks.
Limit to 3 rounds, 6 model calls and 90 seconds. Do not publish.
Return draft, evidence and untested items, or BLOCKED/INCOMPLETE with remaining failures.
