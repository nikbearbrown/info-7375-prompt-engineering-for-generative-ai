Use a bounded routing recipe

Classify T-104 as billing, technical, account or product; return REVIEW for mixed or unsupported requests. Quote the supporting ticket phrase.
Validate label and fit before dispatch. Invoke only the selected handler.
For billing, read only O-104 and BILL-3. Draft from the actual amounts and transaction statuses. Do not promise refunds or send anything.
Stop on missing evidence, invalid labels or scope conflicts.
Limit to 2 model calls, 2 reads, 0 retries and 45 seconds.
Return route, private draft, source references and unverified points, or REVIEW/BLOCKED/INCOMPLETE.
