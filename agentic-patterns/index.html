The three classes

  1. Three classes of agentic patternWhat an agentic pattern is, the agentic loop, and the three classes: reasoning (the model decides), workflow (code decides) and loop check (a check decides), with real examples.

Each companion has ten slides: a concrete task, a bounded run, a check, and a stop rule. All traces are illustrative teaching fixtures, not executed agent runs.

In a deck, use ← → to move, N for speaker notes, G for all slides, and F for fullscreen. Print to save every slide.
