# Assignment 08 Memory and Multiple Agents

**Due:** Canvas · **Points:** 100 · **Assessment:** [Lesson 12](../lessons/12-memory-and-multiple-agents/docs/en.md)

Read the [course AI policy](../prerequisites/ai-policy.md) and watch [AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz).

## Implementation 60 points

- Implement versioned records with deep-copy behavior and compare-and-set updates. **18 points**
- Test aliasing, missing keys, successful updates, and stale-write conflicts. **12 points**
- Construct a reproducible two-worker conflict without presenting simulated workers as people. **10 points**
- Produce a premortem covering lost updates, stale reads, ambiguous ownership, and unsupported memory claims. **12 points**
- Identify what the memory record does not contain, including truth, identity, authority, consent, and evidence. **8 points**

## Submit

Ship the memory implementation, tests, conflict trace, and premortem. Include [Frictional](../prerequisites/frictional.md) **10 points**, [GitHub posting](../prerequisites/github-submission.md) **10 points**, and [Relative Quartile](../prerequisites/relative-quartile.md) **20 points**. An explainer video is optional.
