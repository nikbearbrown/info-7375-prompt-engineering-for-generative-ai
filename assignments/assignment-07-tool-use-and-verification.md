# Assignment 07 Tool Use and Verification

**Due:** Canvas · **Points:** 100 · **Assessment:** [Lesson 11](../lessons/11-tool-use-and-verification/docs/en.md)

Read the [course AI policy](../prerequisites/ai-policy.md) and watch [AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz).

## Implementation 60 points

- Implement strict schema validation and Python tool dispatch for the specified teaching tools. **18 points**
- Reject unknown, extra, Boolean, non-finite, malformed, and overflow-producing inputs. **12 points**
- Preserve authentic tool-use, tool-result, and bounded-error traces. **10 points**
- Build an evidence matrix mapping each final claim to tool output and an independent check. **12 points**
- Explain why protocol completion and a narrated answer do not establish factual verification. **8 points**

## Submit

Ship the dispatcher, tests, trace, and tool evidence matrix. Include [Frictional](../prerequisites/frictional.md) **10 points**, [GitHub posting](../prerequisites/github-submission.md) **10 points**, and [Relative Quartile](../prerequisites/relative-quartile.md) **20 points**. An explainer video is optional.
