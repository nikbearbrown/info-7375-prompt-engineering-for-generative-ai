# Graded Assignments

Assignments are the graded submissions for INFO 7375. They are due on the ten-day cadence published in Canvas. The lesson exercises, builds, quizzes, and artifact briefs are ungraded **Assessments** used to prepare for these Assignments.

Every Assignment is worth 100 points:

| Component | Points |
|---|---:|
| Implementation of the named Assessments | 60 |
| [Frictional](../prerequisites/frictional.md) | 10 |
| [GitHub version posting](../prerequisites/github-submission.md) | 10 |
| [Relative Quartile](../prerequisites/relative-quartile.md) | 20 |
| **Total** | **100** |

Read the [course AI policy](../prerequisites/ai-policy.md) and watch [AI Policy for Professor Bear's Courses | Using AI Responsibly in Class](https://youtu.be/8Ut0Cdl6vMw?si=9w3aEpt1ZyAR4Kiz) before beginning graded work.

Canvas publishes the actual due date and any section-specific adjustments. A brief never authorizes the use or disclosure of restricted data. Claude Code is assumed; direct API calls are optional only where explicitly identified.

## Required submission shape

Upload the matching version to Canvas and GitHub. Use `fall-2025/first-name-last-initial/assignment-XX/` unless Canvas names a different term folder. Include `README.md`, `FRICTIONAL.md`, Python implementation, tests, and evidence. Put the GitHub folder URL and final commit hash in Canvas.

An explainer video is optional and has no separate points. Brutalist is one optional production workflow. A submission without a video can earn full credit.
