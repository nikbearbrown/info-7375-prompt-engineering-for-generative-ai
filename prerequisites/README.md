# NEU course prerequisites

This section is **only for students taking INFO 7375 at Northeastern**. It covers course participation and production setup, not the book's instructional chapters. Independent readers do not need these video tools to use the Python lessons.

## Before graded work

Read the [AI policy](ai-policy.md) and [Relative Quartile rubric — 20/100 points](relative-quartile.md). AI assistance is allowed; citation, understanding, honest evidence, and refinement remain your responsibility.

Read the [100-point Assignment structure](../ASSESSMENT.md): every 10 days, 60 implementation + 10 [Frictional](frictional.md) + 10 [GitHub version posting](github-submission.md) + 20 Relative Quartile. Lesson Assessments are ungraded.

## Optional recorded explanations

1. Confirm your [NEU Claude Code access](../docs/neu-claude-access.md) and complete the [Python setup](../docs/setup.md).
2. Choose an explainer workflow. [Explain your assignment with Brutalist](brutalist-video.md) is an optional tutorial, not a required tool. Other suitable workflows are welcome; clarity and professional quality are evaluated, not the software used.
3. Use a completed Python exercise for practice. Keep film projects in [youtube/](../youtube/README.md), separate from the toolkit.
4. Submit the required Assignment version to GitHub and Canvas. An optional explainer may support Relative Quartile quality; it has no separate points.

This preparation does not add a Week 2 assignment or change the fifteen-lesson sequence. Progress Reels are optional explainer opportunities, not required graded milestones. The video toolchain is separate from the Python curriculum; no paid media account, API credits, or public upload is required.
