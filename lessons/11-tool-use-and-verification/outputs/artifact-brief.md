# Week 11: tool evidence matrix

This is a submission brief, not a completed student artifact.

Ship tool schema, validation rules, request/result trace, and a matrix pairing each final claim with evidence and an independent check.

Include your name, course number, task scope, input provenance, implementation decisions, exact commands, observed results, failed cases, remaining limitations, Claude usage disclosure, student/external code estimate, license, and PEP 8 style declaration. Explain one decision you revised after testing.

Acceptance: another student can reproduce the offline behavior and identify what still needs human verification. Do not include credentials or restricted source material.
