# Week 4: agent trace

This is a submission brief, not a completed student artifact.

Ship a trace with turn number, action, observation, stop reason, and the evidence that would justify completion.

Include your name, course number, task scope, input provenance, implementation decisions, exact commands, observed results, failed cases, remaining limitations, Claude usage disclosure, student/external code estimate, license, and PEP 8 style declaration.
