# Claude at Northeastern: start here

**INFO 7375 assumes you have Claude Code through NEU. Every exercise uses that account.** This is the instructor's course-access assumption. If you found this public repository independently, you need your own Claude Code-enabled account.

[Northeastern's Claude portal](https://claude.northeastern.edu/) is the university entry point. Its public overview says active students, faculty, and staff receive enterprise Claude access through SSO, with advanced features and generous usage allowances. It links onboarding, training, responsible-use guidance, and IT support. It states that Anthropic does not train on institutional inputs. Review is required before uploading confidential, personal, or restricted research data. Its API FAQ directs readers to IT for current availability. Summary checked 2026-09-06; use the portal for current details rather than treating older model names there as a course requirement.

Use Claude Code to build, run, inspect, and explain your Python work. A local reference script can run without making an API request even when Claude Code helps you develop it. Direct API exercises are separately marked --live and may consume API credits; they are optional extensions, not prerequisites for the weekly coursework. University account access does not by itself establish an API budget.
