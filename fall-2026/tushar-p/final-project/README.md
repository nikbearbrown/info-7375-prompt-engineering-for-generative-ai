# Agent Proving Ground

Agent Proving Ground will be a Go harness that runs an AI coding agent on small, self-contained tasks inside an isolated sandbox. It will record every step the agent takes as a trace, and it will decide whether each task was done by running deterministic tests, never by taking the agent's word for it. Nothing is built yet; see `PLAN.md` for the build plan.

Changes since the October pitch will be listed here as the project evolves.
