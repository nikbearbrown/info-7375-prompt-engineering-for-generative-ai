# My judging rule (written before I judged anything, 2026-11-25)
For each posting on the blind sheet I answer one question: **is this posting worth Nadia Okafor's time?** (fictional persona, `persona/resume.json`: entry-level data analyst, MS in Information Systems, at most 3 years, SQL / Python / Tableau / Power BI / Excel / dbt / Looker / Snowflake / A/B testing / ETL).

- **y**: an analyst-type role she could realistically get and would want: analytical work with her kind of tools, and not asking for more than about 3 years.
- **n**: not her kind of job (engineering, sales, legal, design ...), or clearly too senior (senior/lead/manager, or the posting asks for 4+ years).
- **?**: the posting doesn't say enough for me to decide.

I judge from the posting itself (title, location, text), **not** from my filter's words. The sheet doesn't show the filter's verdict or which group (random reject, close call, kept, held-out) an item came from. I don't open `audit/sets.json` until I've finished.
