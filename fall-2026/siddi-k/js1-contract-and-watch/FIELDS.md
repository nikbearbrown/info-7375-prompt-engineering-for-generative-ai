## Posting: Greenhouse `GET /v1/boards/databricks/jobs?content=true`

Every one of the 901 postings in the 05:50 ET snapshot has these fields:

| Field | Notes |
|---|---|
| `id` | numeric, unique across the board; the watch remembers these |
| `title` | free text, e.g. "Senior AI Engineer - FDE (Forward Deployed Engineer)" |
| `location.name` | free text; may list several cities joined by `;`, or "United States", "Remote - United Kingdom" |
| `departments[].name` | e.g. "Executive Engineering - Pipeline" |
| `offices[].name` | e.g. "San Francisco, California" |
| `content` | the full description as escaped HTML (requirements, pay range, etc. are inside this text) |
| `first_published`, `updated_at` | ISO timestamps |
| `absolute_url` | the human-facing posting page |
| `metadata[]` | "Company Assignment", "Career Page Posting Category" |
| `requisition_id`, `internal_job_id`, `company_name`, `language`, `application_deadline` | |
