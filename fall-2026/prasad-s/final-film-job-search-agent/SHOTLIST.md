# SHOTLIST: WorthLoop final project film

What is on screen in each beat. I decided what each beat shows; Claude
Code designs it with the Brutalist toolkit.

Rules for every beat:
- Labels (ILLUSTRATION, CONSTRUCTED, PLANNED, FICTIONAL) stay up for the
  whole beat, not a flash at the start.
- Things appear as the narration names them.
- Mechanisms move: B9, B11 and B16 are animated, not static.
- Company and project names are plain text, never logos.
- A claim from a source carries a small source line on screen.
