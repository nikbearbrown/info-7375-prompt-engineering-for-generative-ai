## What this is
A film in the four parts the assignment asks for:
1. **Executive summary** (B00–B03): a tool that reads logs from a failing backend service, names the likely cause, and cites the exact lines that prove it, or hands the case to a person.
2. **Introduction** (B04–B06): Microsoft's RCACopilot and Datadog's Bits AI SRE, and why an open, re-checkable test bench differs.
3. **Methods** (B07–B13): data from deliberate fault injection, the agent loop, tool limits, stop rules, the human gate, and resources.
4. **Evaluation** (B14–B17): three checks per run, a keyword baseline, and what result means it worked or didn't.

**Nothing in the project is built yet.** Every drawing carries an on-screen "constructed sketch" tag, and no results are shown. The detail is in `APPENDIX.md`.

## How to rebuild
Same environment and toolkit patch as the pitch film (see `../final-project-film/BUILD-PROMPT.md`), then in a reel folder holding `src/` and `SOURCES.md`:

```bash
python3 make_sheet.py
(cd .. && python3 $TK/runtime/scripts/generate_audio_kokoro.py cite-the-line-project-film)
ffmpeg -v error -i mp3/beat-BOUT.mp3 -af "apad=pad_dur=1.0" mp3/b.mp3 && mv mp3/b.mp3 mp3/beat-BOUT.mp3
python3 sync_durations.py
bash check.sh
(cd .. && $TK/art run cite-the-line-project-film --height 2160 && $TK/art final cite-the-line-project-film --height 2160 --out cite-the-line-project-film/exports/landscape)
```

The narration is the free local Kokoro voice reading my first-person script.
