# PROMPTS — "Early Bird"

## Image / video generation prompts
**None.** No text-to-image, no text-to-video, no AI stills, no stock. Every frame is a deterministic render of a Remotion composition; there are no open slots and no beat-prefixed requests.

## Narration
Local Kokoro (`am_onyx`) via `runtime/scripts/generate_audio_kokoro.py`; cost $0.00. Respellings are written into `narration_text` itself (see SCRIPT.md); the toolkit pronunciation file was not changed for this film.

| Written | Said | Why |

| INFO 7375 | Info seventy-three seventy-five | Kokoro reads digits literally |
| Commure | Kuh-mure | default heard as "commuter"/"Commuerre"; five spellings tried, "Kuh-mure" heard as "come your", closest to kuh-MYOOR |
| Screenr | Screener | the repo name has no vowel before r |
| FastAPI / LangGraph | Fast A P I / Lang Graph | spoken as two words |
| "What could sink it" | "What could break it" | "sink" heard as "sync" |
