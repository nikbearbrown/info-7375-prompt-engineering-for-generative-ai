# SHOTLIST - Early Bird final project film

Typed work order. Every beat is one reel-local Remotion scene, `EbwScene` (registered in `runtime/remotion/src/Root.tsx`, drawing code in
`runtime/remotion/src/ebw/engine.ts`, generated by `port_engine.py`). The scene is a pure function of time, `t = t0 + frame / fps`, with
sentence start times from `timeline.json`. There are no open slots: every beat is rendered through `remotion_scenes.py`.

| Beat | Section | Type | Pattern | What is on screen |
|---|---|---|---|---|
| B00 | OPEN | REMOTION | EbwScene | sunrise logo, course tag, title; window rises in; cursor enters |
| B01 | IDEA | REMOTION | EbwScene | Overview page: headline, why-it-matters card, sample report rows, notification |
| B02 | LANDSCAPE | REMOTION | EbwScene | three tool cards (two NOT YET RUN, greenhouse-watch I RAN THIS with KEPT stamp), banner with spotlight |
| B03 | BUILD | REMOTION | EbwScene | six-step pipeline; 81 dots, 69 grey out, 12 move through judge, match, order, report |
| B04 | SETUP | REMOTION | EbwScene | Check setup button with spotlight; modal with four toggles |
| B05 | TEST | REMOTION | EbwScene | four checks, Commure replay counter, labels-locked toggle, side panel (worked if, did not, known risk) |
| B06 | CLOSE | REMOTION | EbwScene | closing lower third |
