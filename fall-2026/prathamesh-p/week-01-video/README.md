**Concept:** expected count (665.24) versus observed count (630) for token 2 in the seed-7 run of the Chapter 1 code. 665.24 is what the distribution assigns on average (1000 × 0.6652409557748218). 630 is what one seeded sample of 1,000 draws actually produced. **Why this concept:** I picked this one because main.py already prints both numbers, so every figure in my video is real and reproducible, and the gap between 665.24 and 630 is small enough to explain completely in under three minutes.

## Rebuild on Windows (native, no WSL)

Tested on Windows 11 with Git for Windows (Git Bash), Python 3.11.9 (`py` launcher), Node 24 / npm 11, and FFmpeg 9.0.2 (`winget install Gyan.FFmpeg`). The pipeline is free and local, with no API keys. `scenes.py` uses only paths relative to this folder. It needs this folder and the `brutalist.art` checkout **side by side in the same parent folder** (the commands below use `C:\info7375`; any parent folder works if you change those command paths).

**1. Get the two repositories at the recorded revisions** (PowerShell):

```powershell
cd C:\info7375
git clone https://github.com/nikbearbrown/info-7375-prompt-engineering-for-generative-ai
git -C info-7375-prompt-engineering-for-generative-ai checkout b293224d5c6f078ce5f793c7ea0f73c9af3f19a0
git clone https://github.com/nikbearbrown/brutalist.art
git -C brutalist.art checkout cd4bf20904be4e7d63babd9622b17963c2361b27
```

Put this folder at `C:\info7375\week-01-video`.

**2. Apply the three local toolkit patches** (not committed upstream; each fixes a problem found on Windows, see FRICTIONAL.md):

```powershell
cd C:\info7375\brutalist.art
git apply C:\info7375\week-01-video\brutalist-setup-local-patch.diff               # ElevenLabs guard skips youtube/
git apply C:\info7375\week-01-video\brutalist-compile-local-patch-cumulative.diff  # drawtext path escaping + timecode inside title-safe
git apply C:\info7375\week-01-video\brutalist-remotion-npx-local-patch.diff        # npx lookup via shutil.which
```

**3. Create the Python 3.11 venv with a `python3` alias** (the toolkit calls `python3`, which on Windows is otherwise the Microsoft Store stub):

```powershell
py -3.11 -m venv .venv
Copy-Item .venv\Scripts\python.exe .venv\Scripts\python3.exe
```

**4. Install and check the toolkit** (Git Bash, from `C:\info7375\brutalist.art`). `PYTHONUTF8=1` is required on Windows, because otherwise Python writes cp1252 and the toolkit stops on characters like `→`:

```bash
source .venv/Scripts/activate
export PYTHONUTF8=1
./setup --install     # Python deps, Remotion node deps, fonts, Kokoro model (~340 MB)
./setup               # readiness table
```

Also install **EB Garamond** and **Oswald** into Windows itself (setup copies them to `~/.local/share/fonts`, which Windows doesn't read). MiKTeX is only needed for equation beats, and this video has none.

**5. (Optional) Re-verify the numbers** (PowerShell):

```powershell
cd C:\info7375\info-7375-prompt-engineering-for-generative-ai
py -3.11 lessons\01-randomness-and-first-prompts\code\main.py     # expect counts {"1": 268, "2": 630, "0": 102}
py -3.11 C:\info7375\week-01-video\evidence\seed7_sequence.py     # regenerates the B04 sequence and checks the counts
```

**6. Build** (Git Bash, venv active, `PYTHONUTF8=1` set, from `C:\info7375\brutalist.art`). Also set `WEEK01_REEL_DIR` to this folder: the toolkit's GATE A pre-check runs an isolated copy of `scenes.py` in a temp folder, and this variable is how that copy finds the beat sheet and evidence files. Renders from the reel folder don't use it.

```bash
export WEEK01_REEL_DIR=/c/info7375/week-01-video
python3 runtime/scripts/generate_audio_kokoro.py /c/info7375/week-01-video      # narration first: measured durations are the clock
./art run   /c/info7375/week-01-video --height 1080                              # review cut + QC gates → week-01-expected-vs-observed-slate.mp4
./art final /c/info7375/week-01-video --height 1080 --out /c/info7375/week-01-video/final
```

The first Remotion render downloads a headless Chrome (about 270 MB, free). Each scene reads its beat's measured audio duration, so if regenerated audio differs slightly the visuals still line up.
