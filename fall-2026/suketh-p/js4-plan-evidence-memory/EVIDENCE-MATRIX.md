Chapter 11 and the brief ask four things about every claim the agent makes about a posting that the student would rely on:

- which check supports the claim;
- what failure that check catches;
- why the check fails differently from whatever produced the claim;
- whether the check was run.

## The two watchers

The Anthropic and Databricks watchers run the same code and the same pinned rule on different boards' text. They are two workers, not two opinions: anything the rule gets wrong, both get wrong. For the counts and new postings, the independent checker is the second route. In JS4, nothing checks the rule's verdicts.
