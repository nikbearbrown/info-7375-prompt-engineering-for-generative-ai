# The sheets Claude Code gave the student

So a reader can see what help the student had for each part they own. Each sheet holds the brief's or a chapter's questions, and facts where the student needed them. No sheet holds an answer. They are kept as `.txt` copies, byte-for-byte, of the files Claude Code wrote in the student's local `Assignment 7/` folder. The times are the files' last-saved times (EST).
