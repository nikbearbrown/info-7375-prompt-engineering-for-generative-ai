## 5. How to record and apply decisions

1. Open `labels/review_decisions.csv` (one row per posting). Edit only `status`, `final_verdict`, `final_reason`, `reviewer_note`.
   - agree: set `status` to `approved` and leave the final columns empty;
   - disagree: set `status` to `corrected`, `final_verdict` to relevant / not / unsure, and `final_reason` to a short phrase without commas;
   - not yet looked at: leave `pending`.
2. `python3 -m js3.review status` shows progress; `python3 -m js3.review doc` refreshes this document.
3. `python3 -m js3.review apply --pending blank --dry-run` shows what would change; drop `--dry-run` to write the two verdict CSVs.
   `--pending blank` empties unreviewed rows so measurement reports them as unlabeled; `--pending keep` leaves Claude's suggestion in place for them (then the measurement is partly Claude's judgment).
4. `python3 -m js3.batch_label check` confirms the CSVs and counts rows that differ from the suggestion.
