# Labeling rule (written before labeling, 2026-11-25)

Question for every posting: is this worth Priya Nair's time to look at?

- **relevant**: an individual-contributor engineering role whose main work is building, training, deploying or serving ML/AI models, or building the ML/data platforms and pipelines they run on. Senior and Staff levels still count (FILTER.md v1 keeps them).
- **not**: sales, solutions or customer-facing, recruiting, operations, legal/policy, people management, non-ML software roles, or anything requiring a security clearance.
- **unsure**: the text shown is not enough to tell.

Judged from the sheet text only (title, location, first 800 characters). Reason: one short phrase, no commas.
