Status: agent-checked by Claude Code on 2026-11-21, and re-checked row by row against the re-recorded
narration on 2026-11-23. Rows whose spoken wording changed in that recut are marked **Re-recorded
2026-11-23** in their note, with the reason.

Rule for this film: nothing of TraceCase exists yet, and the film says so out loud in its last beat
("No TraceCase code exists yet. Everything you just heard is what I'm going to build"). Elsewhere the
narration uses the descriptive present for design properties — B04 says "It's built so you can check
it", meaning *this is how it is designed*, not *this is running today*; `BUILD-PROMPT.md` states that
same rule in the same words, so the two documents do not disagree. Every picture of the product
carries an on-screen "constructed" tag, so no frame implies a working system. Claims about other
people's work are quoted from their own public material, with the date read.
