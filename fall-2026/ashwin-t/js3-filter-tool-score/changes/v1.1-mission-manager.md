# Change v1.0 → v1.1: "Mission Manager" exception

Implemented by Claude Code on 2026-11-25 on Ashwin's instruction in chat (pasted text), after
`audit/FALSE-FRIENDS.md` (`77daf2d1`) documented the false match.

## What this change is, and what it is not

It **corrects a demonstrated keyword error.** In v1.0 the seniority term `manager` fired on "Mission Manager", which
the postings themselves describe as a product: "Mission Manager is Palantir’s PaaS…".

It does **not** establish:
- **improved accuracy:** no measurement here shows the filter is more accurate overall;
- **suitability:** it says nothing about whether Supriya would want these jobs. They ask for "3+ years of
  professional software development experience" and "1+ years of experience as a mentor, tech lead or leading an
  engineering team".

## The one object changed

`filters/v1.1.json` is `filters/v1.0.json` with one new key, plus the `version` and `document` labels. The test
`tests/test_v11_mission_manager.py::test_only_one_object_changed` checks this.

```json
"seniority_exceptions": {"manager": ["mission manager"]}
```

`jobfilter/filter.py` gained support for that key. When a title already has a role phrase, the listed phrase is
taken out before that one seniority term is checked. A second "manager" anywhere else in the title still excludes
it, and so does every other seniority term. Without the key, as in v1.0, behavior is unchanged: re-running
`python3 -m jobfilter.run v1.0` reproduced the committed v1.0 outputs byte for byte (checked 2026-11-25).

## Regression tests (`tests/test_v11_mission_manager.py`)

- **The observed title passes the gate in v1.1 only.** That is "Software Engineer - Mission Manager", plus a comma
  variant. The gate records `seniority_exceptions_applied`.
- **These stay excluded:**
  - "Software Engineer - Engineering Manager" and "Software Engineer - Product Manager" (`manager`);
  - "Software Engineer Manager - Mission Manager", which has a second, genuine `manager`;
  - "Senior Software Engineer - Mission Manager" (`senior`);
  - "Software Engineer - Mission Manager Lead" (`lead`);
  - "Staff Software Engineer, Mission Manager" (`staff`).
- **No role phrase still rejects:** "Mission Manager" and "Engineering Manager, Mission Manager".
- **Development decisions** differ from v1.0 on exactly the two postings above.
