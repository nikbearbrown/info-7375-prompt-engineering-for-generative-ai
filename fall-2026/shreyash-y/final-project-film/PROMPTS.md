# PROMPTS — open slots

## Executive summary

No beat in this film is waiting on outside media, so there are no generation prompts.
Every slot is filled by local Manim or Remotion code (see SHOTLIST.md). No paid or
AI image/video generation was used.

The one prompt that appears in the film is the viewer prompt in BHTF. It is a
suggestion for the viewer to run, not something run for the film:

```
BHTF  Here is a document. Answer my question only with a word-for-word quote from it.
      If no sentence answers it, reply exactly: not in the document.
```
